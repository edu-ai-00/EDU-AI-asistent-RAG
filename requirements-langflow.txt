# Extra deps installed ON TOP of the official langflowai/langflow image.
# Unpinned on purpose: the image runs Python 3.14, and the old 3.11-era pins
# (cryptography==43, snowflake==3.14.0, tiktoken==0.9, ...) have no cp314
# wheels. The Dockerfile installs these with a constraints file generated
# from `pip freeze` of the base image, so NOTHING Langflow ships can be
# upgraded/downgraded by this step — our additions must fit or the build
# fails visibly.

pdfplumber
markitdown[docx,pptx,xlsx]
chardet
jsonschema
psycopg2-binary

validators

                   # PIN drzi paritu s search image — eduai_normalize se sem
                   # instaluje --no-deps, takze jeho vlastni pin sem nedosahne.
