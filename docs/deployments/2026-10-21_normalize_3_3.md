# Deployment: eduai_normalize 3.3.0 (negation, stop-words, diacritics), synonym groups 217

> **Prepared 21 Oct 2026, not deployed.** Verified on the lab installation only
> (no QA packs, no documents in its database).

## What changes

- `eduai_normalize` **3.1.0**: a Czech lemma keeps its negation. simplemma 2.0.0
  reduced "nesmím" and "smím" to the same `smět`; now `nesmět`. Rule in
  [`lemmatizer.py`](../../search/eduai_normalize/eduai_normalize/lemmatizer.py),
  cases in the [parity vectors](../../contracts/parity/cs-normalization-vectors.json).
- `eduai_normalize` **3.2.0**: the lemma and stem branches judge a stop-word
  by its SURFACE form before reducing. 44 of the 155 Czech index stop-words
  used to leak (jsou → stem `jso`, budou → `bud`, mezi → `meh`; 18 % of the
  JPZ phrasings), some colliding with content words ("během" → `beh` as
  "běh", "této" → lemma `teta`). English profits too ("does" → `doe`).
  Not migration 211's reduced-form columns: matching the stem `beh` would drop
  "běh" as well. The QA measurement moved no outcome (coverage reads lemmas,
  exact matches pass on the norm form); the gain is for document retrieval,
  which the lab could not measure without documents.
- `eduai_normalize` **3.3.0**: a Czech word typed WITHOUT diacritics that the
  dictionary does not know as typed is lemmatized through its spellings with
  diacritics, when they all agree on the lemma ("zacina" → začínat; "muze"
  stays, muže/může disagree; "rada" stays, it is a word). The spellings are
  generated and looked up in simplemma's dictionary — no reverse map (that
  measured +90 to +177 MB per process). detect_lang's dictionary vote counts
  such words, so Czech without diacritics is recognised: 45 → 4 of 110 JPZ
  questions undetected. On the JPZ set, exact matches for diacritics-less
  variants 61 % → 96 %; nothing else moved. The search service preloads the
  dictionary at start (0.3 s per worker).
- `qa_lexical` and `qa_vector` give **no curated answer across opposite
  polarity** ("nepřijde" vs "přijde"); `qa_lexical` offers the entry as a
  suggestion instead (`negation_conflict` in
  [`qa_common.py`](../../search/app/nodes/qa_common.py)).
- [Migration 217](../../postgres/migrations/217_synonyms_meeting_groups.sql): ten
  single-word synonym groups (syn/dcera/dítě/žák/uchazeč, stravování, PPP,
  matematika, čeština, učitel, grades 1, 2, 4, 5).

Measured with [`tools/lab/variants`](../../tools/lab/variants/README.md) on the
JPZ set (110 questions, 640 variants): flipped-negation questions answered with
the original curated answer 39/39 → 0/39 (all 39 offered as a suggestion);
synonym variants answered 79 % → 100 %; diacritics-less and typo variants
unchanged.

## Order

1. Build **both** images; one side on 3.0.0 reduces differently.

   ```bash
   docker compose build edu_ai_search edu_ai
   docker compose up -d edu_ai_search edu_ai
   docker exec -i edu_ai_search python -c "import eduai_normalize as e;print(e.__version__)"
   docker exec -i edu_ai /app/.venv/bin/python -c "import eduai_normalize as e;print(e.__version__)"
   ```

   Both must report `3.3.0`.
2. Migration 217. It lives in `postgres/migrations/` and is listed in the
   release manifest [`R217`](../../postgres/releases/R217.json), generated on an
   isolated reference from B216. The runner (`scripts/migrate.py apply`) is
   approved for isolated synthetic databases only
   ([spec](../../specs/active/spec.migration-registry.md)); taking over an
   existing installation (D11) is not decided, so this note does not claim a
   supported upgrade path for one.
3. **Re-ingest every QA pack and every document.** Stored `lemma_text` and
   `stem_text` were built with 3.0.0: a stored "nesmí" still reads `smet` and
   no longer meets a 3.3.0 query "nesmím" (`nesmet`), stored stems still
   carry the leaked stop-words, and words a document typed without
   diacritics keep their old lemma. The norm form is unchanged, so matching
   degrades instead of failing, but the fixes only work after the re-ingest.
4. Parity: `contracts/parity/check_vectors.py` (command in
   [AGENTS.md](../../AGENTS.md)) must pass.

The stored reduced forms of `qa_stopword`, `qa_blocklist` and `qa_synonym` were
recomputed on 21 Oct 2026: no row differs because of these changes (the
guard's phrases are stored with diacritics; meta and identity phrases are
matched folded, not lemmatized). 27
`qa_synonym` rows differ from a recomputation for OLDER reasons (the de/es
interrogative groups, "začít/začínat", "fotit"), the drift migration 211
already names ("sjednotit až s přepočtem"); not touched here.

## Replay on the production log (22 Oct 2026)

A production dump (4 442 logged questions, 373 active QA entries, 1 348
chunks) was replayed with [`tools/lab/replay`](../../tools/lab/replay/README.md):
old code on data ingested by the old code against 3.3.0 + migration 217 on data
re-ingested by 3.3.0. No question got a different curated entry. 42 questions
newly answered from QA (mostly right: questions about the date of the entrance exam,
a test in Czech, the canteen), 23 no longer (9 of them wrong before, e.g. a question
about what not to bring to the exam answered with the list of allowed aids; one
question asked 12× is now only a suggestion: the old answer rested on the leaked
stop-word stem `jso`). 3 questions (8 log rows) newly get a wrong confident answer,
e.g. a short question about phones in school leading to an answer about grades in
the entrance procedure (the restored lemma `škola` plus the verb reach coverage 0.61).

Two decision-logic fixes were measured and **rejected**: breaking a rank tie by
coverage turned 105 more questions into confident answers, many wrong (the
"rank tie → suggestion" rule is a real safeguard); weighting a negated word by
its positive form changed one question, for the worse. The remaining cases are
for the curated data (alternatives, an entry for an ambiguous question), not
for the ranking.

The production also lemmatizes differently from this repository (stored
`nepřítomnost` → `přítomnost`, `mám` → `mama`): it runs an older simplemma.

## Not covered

The standalone word "ne" (an index stop-word), "nikdy", "žádný", "bez";
diacritics-less words whose spellings disagree on the lemma (~25 % of the JPZ
words, "muze", "stejne"), which a frequency from the school's own corpus could
decide later; other languages than Czech. `qa_vector`
and the generated answer were not measured (no OpenAI key on the lab).
